# CTMC Stationary Distribution

A Python program that calculates the stationary distribution of a Continuous-Time Markov Chain (CTMC).

## Features
- Enter the number of states.
- Build the infinitesimal generator matrix Q.
- Validate transition rates.
- Calculate the stationary distribution π using πQ = 0.
- Verify that the probabilities sum to 1.

## Requirements
- Python 3
- NumPy

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
